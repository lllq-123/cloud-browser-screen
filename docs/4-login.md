# 第 4 步：小机撞上登录墙，请你在手机上帮它登

> 这一步做完：小机知道什么时候、怎么叫你来登；你在手机上登一次，浏览器就记住了，以后小机都能用。

**为什么需要你**：短信验证码、扫码、人机验证，这些本来就是为了确认「是一个人在登」，无头浏览器自己过不去。以前只能你在电脑上按 F12 导 cookie，或者小机截二维码发来发去。有了虚拟屏幕，你在手机上直接看着登就行。

## 小机做

**1. 打开登录页，把「闲置自动关」调长。**OpenCLI 开的网页闲置一会儿会被自动关掉，你还没登完页面就没了：

```bash
OPENCLI_BROWSER_IDLE_TIMEOUT=900 opencli browser login open https://要登录的网站/登录页
```

这是 OpenCLI 的命令（照小红书那份第 3 篇装的；它开的网页就在虚拟屏幕看的这个浏览器里）。`login` 是会话名，随便起。900 是秒数（15 分钟），从这条命令开始算。单位是秒，这是我们家实测过的。不用 OpenCLI 的，用你平时开网页的办法就行：只要网页开在这个浏览器里、别被自动关掉，虚拟屏幕就看得见。

**2. 在你们的私聊里告诉主人**：要登哪个网站、用哪个号（你们事先说好的那个，拿不准就问）、建议用哪种方式登（一般短信验证码最顺手），再加一句「打开虚拟屏幕，点那张 xxx 的网页」。

**3. 等主人说登完了，确认一下、关掉这张页**：`opencli browser login state` 会列出这张页上的文字和能点的东西，看看有没有账号名、头像、「退出登录」这类登上了才有的字样；或者跑一条你平时要登录才能用的命令。确认登上了，然后：

```bash
opencli browser login close
```

## 你做

1. 打开虚拟屏幕，点小机说的那张网页。
2. 在画面上点一下网页里的输入框（账号、手机号那一栏），然后在下面的打字栏里打字，点「发送」。
3. **打密码之前，先打开「密码」开关**：它只管你手机这一头，下面那一栏打的字显示成圆点，旁边的人看不到；它还会告诉手机「这是密码」，输入法记不记、联不联想，就看各家手机和输入法了。网页那边收到的字和不开的时候一模一样，网页里的密码框本来就显示圆点，所以开不开，画面上看不出区别，这是正常的。
4. 「获取验证码」「登录」这些按钮，直接在画面上点。
5. 看到登录成功了，告诉小机。

## 几种常见的登录方式

| 方式 | 在虚拟屏幕里能不能做 |
|---|---|
| 账号 + 密码 | 能 |
| 手机号 + 短信验证码 | 能：验证码发到那个手机号上，你在打字栏里打进去 |
| 点选文字 / 图片的验证 | 能，就是在画面上点 |
| 扫码 | 画面里的二维码要拿**另一台设备**上的 App 扫。只有一台手机的话，截屏后用 App 扫一扫里的「相册」，这条我们没试过 |
| 页面要求手动拖动 | 用一根手指按住滑块约半秒，再按网页提示拖动、松手。验证结果以网站显示为准 |

## 登录存在哪

存在浏览器的资料目录里，所有会话共用：你登一次，小机以后打开这个网站的任何页面都是登着的，重启浏览器也不丢。过期了就再登一次。

## 别忘了

- **这个浏览器里登着的号，小机都能用。**别把你自己的主号登进去，除非你本来就想让小机用它。
- 你看着某张网页的时候，虚拟屏幕会一直把它留在最前面，不然画面会停住。这期间小机在别的网页上点击、打字会变慢（我们家实测从 1 秒左右变成 6 秒左右，照样能成），你一回到列表就恢复。
